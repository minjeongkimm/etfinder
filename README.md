## 🚀 3. 핵심 기능

### ① 🧭 투자 성향 분석 (Propensity Analysis)

- **간편 선택:** 공격형/중립형/안정형 3가지 타입 중 빠른 선택 가능.
- **상세 분석:** 금융 행동 심리 기반 설문을 통해 정밀한 성향 진단.
- **기술적 특징:** 진단 결과는 User DB에 저장(`UPDATE`)되어 추천 알고리즘의 핵심 변수로 활용됩니다.

### ② 🔍 초정밀 ETF 검색기 (Deep Search)

- **다중 조건 필터:** `수수료 0.1% 이하` + `미국 시장` + `반도체 테마` + `배당` 등 복잡한 조건을 한 번에 검색.
- **기술적 특징:** MyBatis 동적 쿼리(`<if>`, `<choose>`)를 활용하여 수십 가지 경우의 수에 대응하는 최적화된 SQL을 구현했습니다.

### ③ 💡 맞춤형 추천 알고리즘 (Smart Recommendation)

- **로직:** 사용자의 **나이, 투자 성향**과 ETF의 **수익률, 수수료, 안정성(시총)** 데이터를 종합하여 가중치 점수를 산출.
- **기술적 특징:** MyBatis로 1차 필터링된 데이터를 **Java Service 계층에서 비즈니스 로직**으로 정교하게 점수화하여 랭킹을 매깁니다.

### ④ 📊 포트폴리오 & 시뮬레이션 (Simulation)

- **찜하기(CRUD):** 관심 있는 ETF를 내 포트폴리오(찜 목록)에 담고 관리.
- **수익률 계산:** 월 적립액을 입력하면, 과거 데이터 기반으로 "3년 뒤 예상 수익금"을 시각화하여 보여줍니다.

### ⑤ 🔥 커뮤니티 & 실시간 랭킹 (Community & Trend)

- **소통:** ETF 상세 페이지에서 '한줄평(댓글)'과 '좋아요'를 통해 다른 투자자와 의견 공유.
- **트렌드 분석:** 사용자들의 **조회수, 좋아요 수, 댓글 수**를 집계하여 "실시간 인기 ETF TOP 5"를 메인에 노출.
- **기술적 특징:** 검색 로그(Search Log)를 적재하여 사용자 관심사 트렌드를 분석할 수 있는 기반 마련.
    - 조회수 등 빈번한 변경이 일어나는 데이터는 별도 통계 테이블로 분리하여 성능 최적화.

## ⭐ 4. 서비스 차별성

### ✔ vs 네이버 증권 / 증권사 MTS

- “종목명 검색” 대신 **조건 검색** 중심
- 800개 ETF 중 “유령 ETF” 제거 → **알짜 150개만 제공**

### ✔ vs 뱅크샐러드·핀다

- 얕고 넓은 종합 금융이 아닌
- **ETF에 완전히 집중한 전문 서비스**

### ✔ vs 투자 유튜브 / 블로그

- 일방적 추천(X) → **개인화 기반 상호작용**
- 찜 목록 관리 + 수익률 시뮬레이션 제공
